---

## Reporting a Vulnerability

We take the security and privacy of Zero Network Connectivity seriously. As a peer-to-peer offline application, user data is kept locally on device hardware and shared exclusively across the local Wi-Fi subnet.

If you discover any security vulnerability or denial-of-service issue with our socket handling, please **do not open a public issue**. Instead, report it privately to:

📧 **Email:** smartworld.bd.710@gmail.com

Please provide:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept script.
- Affected device models or Android OS versions.

We will acknowledge your report within 48 hours and work with you on a responsible disclosure timeline and patch.
